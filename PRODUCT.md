# IndoTunnel Product Context

## Overview
IndoTunnel is a high-performance developer tool that exposes local servers to the public internet securely (reverse HTTP/HTTPS tunneling agent & gateway).

## Key Features
- Quick CLI execution: `indotunnel http 8080`
- Instant public subdomains (`*.indotunnel.com`)
- Live HTTP request inspection & replaying
- Traffic monitoring, metrics & usage limits (Free, Developer, Pro plans)
- Built for fast latency, low overhead, and developer ergonomics

## Target Audience
Developers, QA engineers, webhook integrators, and dev teams needing public access to local localhost environments.
