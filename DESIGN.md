# IndoTunnel Design System

## Mode
- Persuade (Landing Page) & Operate (Dashboard)

## Visual Direction: Dark Industrial DevTool
- **Primary Background**: Deep Charcoal (`#090d16`, `bg-slate-950` / `bg-zinc-950`)
- **Card & Surface**: Dark Zinc (`#121826`, `bg-slate-900/60`, `border-zinc-800/80`)
- **Accent Colors**: 
  - Neon Emerald (`emerald-400`, `emerald-500`, glowing status badges)
  - Cyber Cyan (`cyan-400`, `cyan-500` active highlights, CLI prompt text)
- **Typography**:
  - UI Font: Sans-serif (Geist/Inter-style system font stack)
  - Code & Terminal: Monospace (`font-mono`, `Fira Code`, `JetBrains Mono`)
- **Components**:
  - Interactive Terminal Emulator in Hero section
  - Sleek glassmorphism borders (`border-emerald-500/20`, backdrop-blur)
  - Live pulse indicators for connected tunnels
  - Clean data tables with status badges (200 OK green, 4xx yellow, 5xx red)
