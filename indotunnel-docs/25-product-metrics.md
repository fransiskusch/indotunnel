# Product Metrics

## Activation

Key activation event:

```text
user successfully creates a tunnel and serves one successful external request
```

## Core Metrics

- signups
- activated users
- tunnels created
- successful external requests
- returning users
- daily active tunnel users
- average tunnel duration
- average bandwidth/user
- percentage of users hitting limits
- webhook usage

## Funnel

```text
Visit landing page
      ↓
Signup
      ↓
CLI installed
      ↓
Tunnel created
      ↓
First external request
      ↓
Second-day return
      ↓
Weekly retention
      ↓
Paid conversion later
```

## Important Early Question

The critical product question is not only:

> How many users registered?

but:

> How many developers repeatedly expose local apps and receive real external traffic?
