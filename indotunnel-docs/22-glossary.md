# Glossary

| Term | Meaning |
|---|---|
| Agent | CLI binary running on developer machine |
| Gateway | Server component receiving public traffic |
| Tunnel | Logical mapping between public hostname and local service |
| Session | One active agent connection for a tunnel |
| Stream | Logical request/response channel over the persistent tunnel |
| Edge | Network entry point closest to public clients |
| Control plane | APIs/auth/configuration/management |
| Data plane | Actual request forwarding |
| Subdomain | Public hostname segment assigned to a tunnel |
| Free tier | Initial no-cost product plan |
